# Research status

This repository implements an experimental system, not a validated finding of general routing benefit. The source release includes a preliminary measured baseline on a small authored task suite; functional fixtures remain simulated examples. The baseline retains unfavorable outcomes and does not establish superiority. A larger preregistered, held-out local-model study with artifact and environment manifests remains future work.

Read `hypotheses.md`, `paper_outline.md` and `../docs/methodology.md` before interpreting measurements. Report negative findings, abstention and constraint violations alongside cost/quality improvements. Archive raw observations and analysis scripts with any submitted paper.
